# Martech Insiders

Next.js site for martechinsiders.com. Scaffolded to match the Velocity B
stack/structure (Next 14.2.5, Tailwind, App Router) for consistency across
sites managed via mediasurface.

Currently a single placeholder page. Blog content and additional pages will
be added once the site's content plan is ready, and wired into the
mediasurface admin at that point (see the mediasurface repo's CLAUDE.md and
site-config.ts).
